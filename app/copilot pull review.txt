getDailyQuestion() loads all question documents via a collectionGroup("questions").get() and then sorts them client-side. This can become very expensive (bandwidth/latency) as the question bank grows, and it runs each time the Home screen ViewModel is created. Consider switching to a deterministic query that returns only 1 (or a small page of) candidate(s) for the given date (e.g., query by randomKey with limit(1) and wrap-around), or persist the selected daily question id in Firestore/Room so the app doesn’t need to enumerate the entire collection.
